Раздел 2

Решение сферических треугольников

Формулы раздела и решение по трём данным элементам.

Элементы и условия

  • Шесть элементов: стороны a, b, c и противолежащие углы A, B, C. Каждый больше 0° и меньше 180°.
  • Треугольник задан тремя элементами. Решить — найти остальные три.
  • Против большей стороны лежит больший угол.
  • Стороны: каждая меньше суммы двух других, сумма всех трёх меньше 360°.
  • Углы: сумма больше 180° и меньше 540°; сумма любых двух меньше 180° плюс третий.
  • Сферический избыток ε = A + B + C − 180° больше нуля.
  • Полярный треугольник: a' = 180° − A, A' = 180° − a и так далее. Три угла решаются как три стороны полярного треугольника.

Порядок решения

  1. Чертёж: что дано и что ищется, где элемент больше 90°, а где меньше.
  2. Условия существования.
  3. Оценка по чертежу и по правилу «против большей стороны — больший угол».
  4. Формула, в которую входят только заданные элементы.
  5. Исследование знака: косинус положителен — элемент меньше 90°, отрицателен — больше 90°. Синус четверть не даёт.
  6. Счёт: углы до 0,1′, функции до пяти знаков после запятой.
  7. Контроль: sin a / sin A = sin b / sin B = sin c / sin C.
В очередную формулу подставляют заданные элементы. Исключение — пара «две стороны и угол против одной» и пара «два угла и сторона против одного»: там следующий шаг уже использует элемент, найденный по синусу.

Основные формулы

Косинус стороны

cos a = cos b · cos c + sin b · sin c · cos A

Три стороны и угол между двумя из них. Отсюда угол по трём сторонам:

cos A = (cos a − cos b · cos c) / (sin b · sin c)

Косинус угла

cos A = − cos B · cos C + sin B · sin C · cos a

Три угла и сторона между двумя из них. Это косинус стороны полярного треугольника.

Синусы

sin a / sin A = sin b / sin B = sin c / sin C

Удобно для контроля. Как расчётная формула требует отдельного выбора четверти.

Четыре рядом лежащих элемента

Обход A, c, B, a, C, b. Крайние — угол A и сторона a, средние — сторона c и угол B:

ctg A · sin B = ctg a · sin c − cos c · cos B

Остальные пять — тем же правилом по кругу.

Пять элементов

sin a · cos B = cos b · sin c − sin b · cos c · cos A

Остальные — круговой перестановкой.

Дополнительные формулы

Их считают по заданным элементам, искомое выходит через тангенс, четверть видна в ходе счёта.

Аналогии Непера

Две стороны и угол между ними → противолежащие углы:

tg[(A + B) / 2] = cos[(a − b) / 2] / cos[(a + b) / 2] · ctg(C / 2)
tg[(A − B) / 2] = sin[(a − b) / 2] / sin[(a + b) / 2] · ctg(C / 2)

Два угла и сторона между ними → противолежащие стороны: в тех же формулах стороны и углы меняются ролями, котангенс полуугла становится тангенсом полустороны.

Правило четверти. Полусумма противолежащих элементов лежит в той же четверти, что и полусумма заданных. Если (a + b) / 2 > 90°, то и (A + B) / 2 > 90°: к арктангенсу прибавляют 180°. Затем A = полусумма + полуразность, B = полусумма − полуразность.

Формулы полупериметра

По трём сторонам, s = (a + b + c) / 2:

tg(A / 2) = √[ sin(s − b) · sin(s − c) / (sin s · sin(s − a)) ]

По трём углам, S = (A + B + C) / 2:

tg(a / 2) = √[ − cos S · cos(S − A) / (cos(S − B) · cos(S − C)) ]

Минус под корнем нужен потому, что S > 90° и cos S < 0.

Формулы Деламбра — Гаусса

Контрольные, связывают все шесть элементов:

sin[(A + B) / 2] / cos(C / 2) = cos[(a − b) / 2] / cos(c / 2)
sin[(A − B) / 2] / cos(C / 2) = sin[(a − b) / 2] / sin(c / 2)
cos[(A + B) / 2] / sin(C / 2) = cos[(a + b) / 2] / cos(c / 2)
cos[(A − B) / 2] / sin(C / 2) = sin[(a + b) / 2] / sin(c / 2)

Сферический перпендикуляр

Косоугольный треугольник можно разбить перпендикуляром на два прямоугольных и решать их по Неперу. В разборе этой программы идёт прямой счёт по формулам выше.

Прямоугольный и четвертной

Прямоугольный — один угол 90°. Четвертной — одна сторона 90°. Четвертной не частный случай прямоугольного: он ему полярен и имеет свой круг.

Прямой угол в круг не входит. Катеты берут дополнениями до 90°. Для прямого угла A, гипотенузы a и катетов b, c порядок такой:

(90° − c),   B,   a,   C,   (90° − b)
Правило I. Косинус отдельно стоящего элемента равен произведению синусов двух несмежных.
Правило II. Косинус среднего из трёх соседних равен произведению котангенсов крайних.

Десять формул при A = 90°:

cos a = cos b · cos c    cos a = ctg B · ctg C
cos B = sin C · cos b    cos C = sin B · cos c
sin b = sin a · sin B    sin c = sin a · sin C
cos B = ctg a · tg c    cos C = ctg a · tg b
sin b = ctg C · tg c    sin c = ctg B · tg b

Катет и противолежащий ему угол одной четверти: оба меньше 90° или оба больше. Иначе треугольника нет.

Четвертной со стороной a = 90°, круг:

(90° − C),   b,   (180° − A),   c,   (90° − B)

Те же два правила. Считают переходом к полярному прямоугольному: каждый элемент заменяют дополнением до 180°, стороны и углы меняются местами, затем возвращаются обратно.

Малый треугольник

  • Малый — не отдельный вид, а приём: стороны малы относительно радиуса сферы, и сферические формулы заменяют плоскими через ряды.
  • Порог: все три стороны не больше 6°. Прямоугольный с малыми катетами остаётся прямоугольным; плоский счёт идёт рядом с точным.
  • Плоские формулы: сумма углов 180°, теорема синусов и теорема косинусов. Расхождение с точным решением даёт избыток ε.
sin x ≈ x − x³/6    cos x ≈ 1 − x²/2    tg x ≈ x + x³/3

До какой величины аргумента замена ещё держит ошибку:

Когда решений два

  • Прямоугольный: катет и противолежащий угол. При одной четверти и sin(катет) < sin(угол) гипотенузы две. Если синусы равны и это не пара 90° и 90°, решение одно: гипотенуза 90°. Пара 90° и 90° треугольник не определяет.
  • Четвертной: та же двузначность у стороны и противолежащего угла.
  • Косоугольный: две стороны и угол против одной из них; два угла и сторона против одного из них. Синус даёт два кандидата, оба проверяют условиями существования.

Типичные ошибки

  • Потеря 180° в полусумме аналогий Непера.
  • В формулу подставлен уже найденный элемент там, где нужны только данные.
  • Катет вписан в круг Непера без дополнения до 90°.
  • Четвертной решён по кругу прямоугольного.
  • Четверть выбрана только по синусу.
  • Плоские формулы применены к сторонам больше предельной таблицы.
  • Нет контроля по синусам.
